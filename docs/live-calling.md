# Phase 2: live calling setup

Live calling is opt-in. Keep `PROVIDER_MODE=mock` for demos. Before enabling `elevenlabs`, configure one multilingual Conversational AI agent and import a Twilio or Exotel number into ElevenLabs with outbound calling enabled. Set `TELEPHONY_KIND` to match the imported phone number's provider. Enable the agent security overrides for first message, language, and system prompt. Add a server tool named `record_outcome` that makes a blocking POST to `https://<public-host>/voice/tools/record_outcome`, sends the `X-Tool-Secret` header, and passes the required `call_id` plus the outcome fields in §7.4 of `PROJECT_STATE.md`. The call ID is passed to the agent as a dynamic variable.

Configure a workspace webhook for both `post_call_transcription` and `call_initiation_failure`, using HMAC authentication and the URL `https://<public-host>/webhooks/elevenlabs`. Enable webhook retries so a transient delivery before the API stores its conversation ID can be delivered again. Copy the generated signing secret to `ELEVENLABS_WEBHOOK_SECRET`. Set a long, random `TOOL_SECRET`; the same value must be configured in the agent tool header. Use HTTPS for any public endpoint.

Give the agent tool these JSON fields: `call_id` (string), `outcome` (enum: `confirmed`, `declined`, `maybe`, `callback`, `optout`), `input_mode` (optional enum: `speech`, `keypad`), `party_size` (optional integer), and `callback_time` (optional string). Require `call_id` and `outcome`. The `call_id` value must come from the per-call `{{call_id}}` dynamic variable, and opt-out must stop the call immediately after recording the result.

Set `PROVIDER_MODE=elevenlabs`, `ELEVENLABS_API_KEY`, `ELEVENLABS_AGENT_ID`, `ELEVENLABS_PHONE_NUMBER_ID`, `ELEVENLABS_WEBHOOK_SECRET`, and `TOOL_SECRET` in the ignored local `.env` file. Restart Compose. The API refuses to start in live mode when required settings are missing. First use a campaign containing only team-owned, consented test numbers; launch explicitly from the dashboard. Keep `MAX_CONCURRENT` low and check the called number, language, outcome tool, opt-out behavior, and webhook before expanding the list.

The provider uses ElevenLabs' native Twilio or Exotel outbound-call endpoint, selected by `TELEPHONY_KIND`. It sends the encrypted contact number only at dial time, with the approved language script and campaign fields. It disables Twilio call recording, stores the returned conversation ID, accepts the authenticated outcome tool call, then verifies and redacts the post-call transcript. It does not persist audio. Keep mock mode available for demos and acceptance work.

The current integration does not verify a real call or certify speech/keypad behavior. Check language quality for English, Hindi, and Malayalam with consented test numbers, measure call setup and conversation latency, and verify keypad input on the actual number type before describing those capabilities as validated. The provider records an `input_mode` only when the configured agent tool submits it.
