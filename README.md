# Project Details

## Overview

Swaram is an event-ops autopilot that turns a template and event details into a live multilingual calling campaign. It runs the full lifecycle (invite, RSVP, reminder, update, attendance) over voice with SMS/WhatsApp fallback, and reuses the same engine for clinic, school and payment communication.

## Problem Statement

Institutions run seminars and workshops across cities and still coordinate attendance by manual phone calls, spreadsheets and one-off blasts.

- **What is the problem?** Reaching hundreds or thousands of people in their own language, capturing RSVPs, and keeping everyone updated when plans change is slow, error-prone and expensive.
- **Who is affected?** Event organisers, clinics, schools and finance teams, plus recipients who get irrelevant, wrong-language or badly timed calls.
- **Why does it matter?** No-shows, missed updates and unreachable contacts waste capacity and trust, and contact lists and call recordings are personal data that is often handled carelessly.
- **Limits of existing solutions:** IVR blasts are one-way and single-language, call centres don't scale, and most tools treat a call as the unit of work instead of the event, so a venue change means re-doing the campaign by hand.

## Solution

Swaram treats the **event** as the core object and calls as one channel in its lifecycle. An operator picks a template, pastes event details and approves auto-generated scripts in each language. Swaram then schedules waves of calls: a hybrid voice agent uses pre-synthesised audio for scripted turns and an LLM only for understanding replies. It captures intent by speech, keypad or both, and handles voicemail, retries and fallback channels. When the organiser edits the event, Swaram diffs the change and re-contacts only the affected confirmed invitees. A dashboard shows outcomes by campaign, language and segment, with one-click actions such as retrying non-responders. Contact data is encrypted, transcripts are redacted, and audio is processed on self-hosted infrastructure.
